# AdPilot Help Center for Claude

A documentation-based, bilingual (English/Italian) skill plugin for merchants using AdPilot on Shopify.

- **Documentation:** https://github.com/Jason-Curro/adpilot-help-center
- **Website:** https://joinadpilot.com/
- **Support:** support@joinadpilot.com
- **Privacy:** https://joinadpilot.com/privacy/
- **Terms:** https://joinadpilot.com/terms/

This plugin helps with onboarding, product scoring, simulations, AI campaign proposal creation, Meta Ads CSV optimization, plan requirements and general troubleshooting. It cannot access a Shopify store, Meta account, billing, helpdesk or private logs, and cannot publish ads or guarantee advertising outcomes.

## Test prompts

- How do I install and start using AdPilot with Shopify?
- Quali sono i limiti dei piani Free, Starter e Pro?
- My Meta Ads CSV is being rejected. What columns do I need?
- Cosa significa il codice ERR-XXXXXX?
- Can you check the charges on my Shopify account? (Expected: clearly explain that account access is unavailable.)

## Updates and provenance

The plugin bundles a reviewed **snapshot** of the public Markdown docs. Rebuild it after material documentation changes and publish a new version. Only the public documentation is included; never copy the private app repository or Git history.

The exact installed content and third-party AI platform terms matter. Do not share passwords, API keys or private customer reports in chat.
