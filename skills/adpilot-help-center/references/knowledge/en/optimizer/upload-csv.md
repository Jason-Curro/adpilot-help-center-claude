# Upload a CSV to the Optimizer

## Before uploading
You need **Pro**, a saved campaign, a compatible CSV, and an optimization option available for that campaign.

## Upload steps
1. Open **Campaigns** and select the campaign.
2. Select **Start optimization** if available.
3. Review the export instructions and required columns.
4. Set the **Period analyzed (days)**; the current form offers **1–90 days** and defaults to 7.
5. Choose the `.csv` report from your device.
6. Select **Analyze** and review the resulting report.

Do not leave the page or send repeated requests while analysis is processing. If the upload is rejected, use [Fix CSV import errors](../troubleshooting/csv-errors.md) and [CSV format and required columns](../optimizer/csv-requirements.md).

## Privacy
Check the report for sensitive data before uploading. The optimization request processes data from your report to generate recommendations. Do not send reports or personal data to chat support.
