# How Meta Ads Optimization works

## What the Optimizer does
The **Optimization** feature analyzes advertising performance exported from Meta Ads Manager. It summarizes results and prepares suggested actions for a saved AdPilot AI campaign.

## Requirements
- An active **Pro** plan to create optimization rounds.
- A previously saved AI campaign proposal.
- A compatible **UTF-8 CSV** report exported from Meta Ads Manager.
- The expected **72-hour interval** between rounds on the same campaign.

## Workflow
1. Open **Campaigns** and select a campaign.
2. Start an optimization when the button is available.
3. Export a Meta Ads report with the required columns.
4. Enter the analyzed period and upload the CSV.
5. Review the recommendations and apply any chosen changes manually in Meta.

**No Meta account connection or automatic ad editing is provided by this flow.** Results depend on the data in the uploaded report, so review its accuracy before importing.
