# When can I optimize again?

## Waiting period
AdPilot's normal interface requires at least **72 hours** between optimization rounds for the **same saved campaign**. On the campaign detail page, the Start optimization action can show a waiting message until the next window.

## What to do
1. Open **Campaigns** and select the campaign.
2. Check whether the optimization action is available.
3. If a waiting period is shown, review the previous report and continue monitoring performance in Meta Ads Manager.
4. Return once the interface indicates that a new optimization is available.

The wait concerns the same campaign; it is not a promise about how often Meta delivers updated reporting data. A public assistant cannot inspect your last round's timestamp or bypass a restriction.

For other issues, see [Fix Optimizer access and report issues](../troubleshooting/optimizer-errors.md).
