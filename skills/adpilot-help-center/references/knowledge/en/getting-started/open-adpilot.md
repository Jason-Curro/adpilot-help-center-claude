# Open AdPilot in Shopify

## Install AdPilot (if you have not installed it yet)
1. Open the [official AdPilot listing on the Shopify App Store](https://apps.shopify.com/adpilot).
2. Select **Install** and sign in to Shopify if prompted.
3. Choose the store where you want AdPilot and review the permissions shown by Shopify.
4. Confirm installation only if you agree with the displayed permissions and terms.

AdPilot's App Store listing is publicly available. Installation completion for a specific store requires that store's Shopify account and was not verified by this guide.

## Before you begin
AdPilot must already be installed on the Shopify store, and you must have access to that store's administration.

## Open the app
1. Sign in to your store's **Shopify admin**.
2. Open the area for installed **Apps**.
3. Select **AdPilot**.
4. Use the app navigation to open **Guide**, **Dashboard**, **Product Ad Score**, **Simulator**, **AI Generator**, **Campaigns**, **Optimization** or **Plans**.

## If AdPilot is not listed
Check that you are in the intended Shopify store and that the app is installed. If AdPilot is not installed, use the verified Shopify App Store listing above. If Shopify reports that you cannot install it, check your store permissions and follow the message shown there.

If the page does not load, follow [Troubleshoot app access](../troubleshooting/access-issues.md). Never send a password or Shopify access token to support.
