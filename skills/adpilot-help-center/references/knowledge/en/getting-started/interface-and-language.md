# Navigation and language

## Main navigation
The app navigation contains **Guide**, **Home/Dashboard**, **Product Ad Score**, **Ads Simulator**, **AI Generator**, **Campaigns**, **Optimization** and **Plans**.

Use **Dashboard** to review your targets and recent activity. Use **Simulator** for forecasts, **Campaigns** for saved AI proposals, and **Optimization** for analysis history.

## Change language
1. Open AdPilot.
2. Find the **EN / IT** language selector in the interface, near the bottom-right corner.
3. Select **English** or **Italian**.
4. The app saves your choice for the store.

Only English and Italian are provided by the current interface. Your saved preference takes priority over the initial Shopify locale selection.

## Troubleshooting
If text does not update, reload the application once. If access fails, use [Troubleshoot app access](../troubleshooting/access-issues.md).
