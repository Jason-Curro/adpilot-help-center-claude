# Find and review saved campaigns

## Find a campaign
1. Open **Campaigns**.
2. Select the saved campaign you want to inspect.
3. Review the product, duration, daily budget and proposed campaign plan.
4. If the option is available for your plan and timing, open **Start optimization** to analyze actual performance data.

The Campaigns area lists saved AI-generated proposals; it is **not** a list of live campaigns fetched from Meta Ads Manager.

## If the list is empty
Create your first AI proposal using [Generate an AI campaign proposal](../ai-generator/create-ai-campaign.md). Free users cannot generate new proposals with the current plan.

If you do not need a saved proposal, read [Delete a saved campaign](../campaigns/delete-campaigns.md).
