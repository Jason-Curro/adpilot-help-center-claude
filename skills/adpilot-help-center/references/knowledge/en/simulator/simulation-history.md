# View and delete saved simulations

## View saved simulations
1. Open **Ads Simulator**.
2. Select a simulation in the history to see its saved parameters and results.
3. In the detail view, use the available delete option only if you no longer need the record.

The Free history shows up to the three most recent entries. Paid plans use a paginated history.

## Deletion and limits
Deleting a simulation removes it from the normal history view. **It does not return a simulation to the current month's allowance.** That allowance counts simulations created during the month, including deleted ones.

Make sure you have saved any information you need before confirming deletion. See [Create an advertising simulation](../simulator/create-simulation.md) for monthly quotas.
