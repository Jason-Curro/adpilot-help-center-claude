# Fix AI Generator issues

## Common reasons a request fails
- **Plan restriction:** Free does not include AI Generator.
- **No available generations:** your included monthly allowance and any eligible extra credits have been used.
- **Invalid product:** choose an active product again.
- **Invalid inputs:** check country, sector, objective, daily budget and duration.
- **Unexpected error:** a service or generation problem may have occurred.

## Safe troubleshooting
1. Open **Plans** and verify your current plan and available generations.
2. Return to **AI Generator** and reselect the product and options.
3. Check numeric fields for whole numbers in the permitted ranges.
4. If an unexpected error appears, note the reference code and approximate time.
5. Avoid repeated submissions while a generation is still running.

The app attempts to return a consumed credit if generation fails, but recovery is not a guarantee for every failure. For discrepancies, contact official support using [What does ERR-XXXXXX mean?](../troubleshooting/error-reference.md); never provide API credentials or private customer data.
