# What does ERR-XXXXXX mean?

## Meaning of the code
An `ERR-XXXXXX` code is a **reference to an application error event**, not a public explanation of the underlying cause. Its presence does not prove that the problem is caused by a particular setting or by Shopify.

## What to record
1. Copy the exact reference code.
2. Note the feature you were using and what you clicked.
3. Record the approximate date/time and the text visible on screen.
4. Contact the current official AdPilot support channel with these details if the issue persists.

A public assistant has **no access to private application logs** and cannot retrieve the event or determine its cause from the code alone.

Do **not** send passwords, access tokens, secret keys, customer information, full private CSV reports or payment-card details. Do not repeat paid or credit-consuming actions just to reproduce an error.
