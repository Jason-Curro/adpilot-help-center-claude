# Troubleshoot app access

## If the app is missing or does not open
1. Confirm that you are signed in to the **correct Shopify store**.
2. Check whether AdPilot appears among the installed apps.
3. Reopen AdPilot from Shopify admin, rather than using an old bookmarked application URL.
4. If the problem looks temporary, refresh once.
5. Note the exact on-screen message, approximate time and affected page.

Access depends on Shopify authentication and the installation in your store. This guide cannot verify your account or change permissions remotely.

## When to contact support
If the issue persists, send the official support channel the error message and a brief description **without passwords, access tokens, private data or payment details**. If an `ERR-XXXXXX` reference appears, include it. See [What does ERR-XXXXXX mean?](../troubleshooting/error-reference.md).
